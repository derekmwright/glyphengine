# Example assets

`crate.png` is generated procedurally rather than sourced, so this repository
carries no third-party art and every binary file in it is reproducible from
code.

It is a 256×256 tiling plank pattern built from two sine bands and a seam
mask. The generator is not committed because it is fifty lines and runs once;
the intent is that example assets stay small, MIT-clean by construction, and
obviously not something anyone should ship in a real game.
