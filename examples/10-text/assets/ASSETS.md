# Example assets

Every binary file here is listed with its source and license. Anything not
listed does not belong in the repository.

| File | Source | License |
|---|---|---|
| `fonts/goregular.png`, `fonts/goregular.json` | Generated by `task font` from Go Regular, via `cmd/msdfatlas -builtin` | BSD 3-Clause, same as the typeface |

There is no `.ttf` here. Go Regular is the Go project's own typeface, and it
arrives as a Go module — `golang.org/x/image/font/gofont/goregular`, already an
indirect dependency of this repository — so `task font` regenerates the atlas
from a source the module system fetches rather than a binary checked in beside
it.

## Why this font

The atlas is a rendering of somebody's outlines, so it inherits their license.
That makes the choice of font a licensing decision, not an aesthetic one.

Most of the obvious candidates are SIL Open Font License 1.1: Inter, Open Sans,
Roboto Flex, Noto, Lato. The OFL is a perfectly good license, but it is a
*copyleft* license for fonts, and it attaches real obligations to anyone who
redistributes this repository — the license text has to travel with the files,
derivative fonts must stay OFL, and the font may not be sold standalone. None
of that is onerous, but all of it would be inherited by every project that
vendors these examples, in a repository whose whole point is MIT.

Go Regular is BSD 3-Clause, the same license as the Go standard library. It
carries no copyleft and no per-file attribution requirement beyond the notice
already covering `golang.org/x/image`. For a Go engine it is also simply the
right typeface.

## Regenerating

    task font

To use your own font instead, pass a path:

    go run ./cmd/msdfatlas -font MyFont.ttf -out assets/fonts/myfont

Whatever license that font carries then applies to the atlas it produces. If
you ship a game on this engine, that obligation is yours, not this
repository's.
